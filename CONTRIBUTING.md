# Contributing

This is a personal engineering notebook for one setup, on one specific machine — not a product. It's public because the documented issues and fixes are likely useful to anyone else running local LLMs on integrated graphics.

Corrections are welcome: wrong facts, broken links, confusing explanations. Open a PR directly for anything small; for anything bigger, open an issue first so we're not both guessing at scope.

Out of scope: feature requests for the setup itself (it reflects one person's actual hardware and choices), rewriting `JOURNAL.md`'s tone (it's a historical log, not edited retroactively except for factual errors), and speculative content or unmeasured numbers — see [AGENTS.md](AGENTS.md) for why.

If you're correcting a technical claim, say how you confirmed it.
